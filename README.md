# 🔲 مولّد رموز QR

تطبيق ويب بسيط وسهل الاستخدام لتوليد رموز QR من النصوص والروابط.

## الميزات ✨

- ✅ توليد رموز QR بسهولة
- ✅ دعم اللغة العربية
- ✅ تحميل الصور
- ✅ نسخ الصور في الحافظة
- ✅ تصميم عصري وجميل
- ✅ يعمل على جميع الأجهزة (ديسكتوب، تابلت، موبايل)

## الاستخدام 🚀

1. اذهب إلى موقع المشروع
2. أدخل النص أو الرابط الذي تريد تحويله إلى رمز QR
3. اضغط على زر "توليد رمز QR"
4. يمكنك تحميل الصورة أو نسخها

- JavaScript (Vanilla)
- QRCode.js Library
